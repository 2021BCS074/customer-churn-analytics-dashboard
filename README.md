# Customer Churn & Business Performance Analytics Dashboard

## Project Overview
This project analyzes customer churn behavior using SQL, Power BI, and Tableau. The goal is to identify customer retention trends, contract-based churn patterns, and key business insights through interactive dashboards and data analysis.

## Tools Used
- SQL (MySQL)
- Power BI
- Tableau
- Excel/CSV Dataset

## Key Insights
- Analyzed customer churn percentage and retention trends
- Identified high churn in month-to-month contracts
- Compared customer distribution by gender and internet services
- Built interactive dashboards for business decision-making

## Features
- KPI Cards
- Churn Distribution Analysis
- Contract Analysis
- Interactive Filters/Slicers
- Business Performance Dashboard
